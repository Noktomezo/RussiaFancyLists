> [!TIP]
> **💡 Описание категорий списков:**<br>
> 🚫 **`Чёрный список` (Blacklist)**: Ресурсы и IP-подсети, заблокированные на территории РФ (точность ~99.9%). Поскольку отдельные диапазоны CDN не публикуются в официальных реестрах, они вынесены отдельно (`cdn`) и объединены в общий бандл (`full-and-cdn`).<br>
> 🌍 **`Геоблокировки` (Geoblock)**: Зарубежные сервисы, ограничивающие доступ пользователям с российскими IP-адресами. Единого официального реестра не существует, поэтому список формируется и валидируется сообществом.<br>
> ⚪ **`Белый список` (Whitelist)**: Домены и подсети, сохраняющие работоспособность в условиях ограничений мобильного интернета (режим «белых списков»).<br>
> ⚡ **`Служебные` (Service / prefer-direct)**: Сервисы со строгими механизмами защиты (WAF/Anti-Bot), сбрасывающие обфусцированный трафик (Zapret, ByeDPI, GoodbyeDPI) или блокирующие известные ASN VPN-провайдеров (в частности, Cloudflare WARP), возвращая ошибки 403 или рейт-лимиты. Рекомендуется направлять напрямую (`DIRECT`), если весь остальной трафик проксируется или обфусцируется.

> [!TIP]
> **💡 Варианты hosts и AdGuard Home:**<br>
> 🧠 **`smart`**: Активно проверяется TLS SNI-рукопожатием. Содержит только проверенные рабочие пары `[IP - домен]` по всем провайдерам, предотвращая поломку неподдерживаемых прокси-серверами сайтов (рекомендуемый).<br>
> 🩹 **Что такое "Костыль" (Crutch)?:** Решение, сопоставляющее домен напрямую с незаблокированным IP-адресом в его подсети (например, CDN/edge-серверы GitHub) для прямого обхода локальной цензуры без использования общих SNI-прокси.<br>
> 🌐 **`-no-crutch`**: Исключает секцию костылей (`# Crutch`). Удобно, если весь остальной трафик у вас идет через VPN.<br>
> ⚡ **`only-crutch`**: Содержит **только** прямые маппинги (костыли). Удобно, если геоблок идет через VPN, но вы хотите напрямую обходить локальные блокировки для отдельных доменов.<br>
> 🛡️ **Формат AdGuard Home (`.adguard.txt`)**: Правила для пользовательских правил / переопределений DNS в AdGuard Home синтаксиса `||домен^$dnsrewrite=NOERROR;A;IP`.

> [!NOTE]
> **🌍 Нужно 100% покрытие геоблоков?**<br>
> Списки hosts и серверы Smart DNS могут маршрутизировать только те домены, которые поддерживаются серверами провайдеров. Для достижения 100% покрытия геоблоков можно попробовать:
> 1. **Бесплатный Relay для Cloudflare WARP**: Бот [@warp_generator_bot](https://t.me/warp_generator_bot) от *llimonix* маршрутизирует трафик через зарубежный релей (`Пользователь -> Зарубежный сервер -> WARP в этой стране -> Интернет`).<br>
>    *Нюанс*: Требуется привязка вашего публичного IP-адреса в личном кабинете бота. При перезагрузке роутера или смене IP у провайдера потребуется привязать новый адрес заново.
> 2. **Поиск зарубежных нод через Warpscout**: Попробовать выбить иностранную ноду напрямую утилитой [warpscout](https://github.com/vernette/warpscout):
>    ```bash
>    warpscout.exe scan -p awg -jc 4 -jmin 10 -jmax 50 -i1 "<r 2><b 0x858000010001000000000669636c6f756403636f6d0000010001c00c000100010000105a00044d583737>"
>    ```
>    Главный критерий при сканировании: значение в столбце `SEEN AS` должно быть не `RU` (например, `FI`, `SE`, `DE`).
